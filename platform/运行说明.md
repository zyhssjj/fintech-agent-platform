# FinTechBase 本地运行说明

## 运行环境

- Windows 10/11
- Docker Desktop（已启动）
- Go 1.25 或更高版本
- Node.js 20 LTS 或更高版本
- Python 3.11 或更高版本，并可通过 `python` 命令访问

## 首次启动

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1
```

脚本会启动 PostgreSQL、Redis、MinIO，并在首次运行时安装前端与 AI 依赖，再分别打开后端、AI 服务、前端三个终端窗口。

启动完成后访问：`http://localhost:3000`。

全新数据库会自动建表并初始化基础演示数据。默认管理员账号为 `admin`，密码为 `Admin@123456`；首次登录后应立即修改。

## 目标机配置

首次执行脚本会从各目录的 `.env.example` 生成 `.env`。以下能力需要在目标机自己的 `.env` 中填写：

- DeepSeek：编辑 `ai/.env` 的 `AI_API_KEY`。
- Outlook：编辑 `backend/.env` 的 `MICROSOFT_*` 配置，并在 Microsoft 应用注册中允许目标机使用的回调地址。
- 139 或其他 SMTP/IMAP 邮箱：在通讯管理的“邮箱配置”中填写目标机测试邮箱、授权码和服务器地址。

压缩包不包含任何真实邮箱密码、授权码、OAuth Token、DeepSeek Key、数据库数据或本机日志。

## 局域网访问

前端默认监听 3000 端口。需要其他电脑访问时，以管理员身份执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\enable-lan-access.ps1
```

脚本会配置 Windows 专用网络防火墙规则并显示局域网 URL。
