# 科技金融企业知识库验收包

## 交付内容

本包包含科技金融企业知识库的完整服务端与管理界面源码、Docker 编排、启动脚本、匿名测试样例和 OCR 模型。

本包不包含任何业务文档、Elasticsearch 索引、用户账号、登录会话、模型 API Key、内部 API Key 或其他运行时凭证。首次启动后，请在系统中配置模型并自行上传验收资料。

## Windows 启动

1. 安装并启动 Docker Desktop，确认 Docker 状态为 Running。
2. 将 `.env.example` 复制为 `.env`。
3. 在 `.env` 中至少填写 `LLM_API_KEY`、`EMBEDDING_API_KEY`、`KNOWLEDGE_INTERNAL_API_KEY`；如需使用同一密钥，可填写相同的有效云端模型密钥。
4. 双击 `start.bat`。首次启动或代码更新后，命令行执行 `start.bat --build`。
5. 浏览器访问 `http://127.0.0.1:8201/`。健康检查地址为 `http://127.0.0.1:8201/health`。

## V2 目录验收

系统仅提供航科君富（38 个三级事项）、膜天君富（34 个）、聚元私募（39 个）。入库时依次选择平台、一级、二级、三级目录；选择上级后可查看概览说明，选中三级后显示归类标准和完整相关文件清单。相关文件只是分类提示，不限制上传文件名。

文档中心与检索页可停留在任一级进行筛选，也可选到三级精确检索。新环境默认没有业务资料，需按新目录上传。账号、模型与 API 凭证不随目录更新清除。

## 用户与接口权限

先在“智能体配置”中创建一个或多个权限凭证，再到“用户管理”新建或编辑用户，为用户勾选多个权限组合。系统会为新用户生成独立的 `wk_user_...` API Key，外部系统使用该密钥调用 `POST /api/v1/retrieve` 或 `POST /api/v1/answer`。用户可检索范围为所绑定有效凭证知识域的并集；智能回答只允许使用具有回答能力的凭证所授权目录。用户密钥仅在创建或重置时显示一次。

## 模型接入

系统首次打开后进入“模型配置”：

- LLM：用于基于证据的问答。
- Embedding：用于文档入库和向量检索，必须配置。
- Rerank：可选；未配置时自动回退为 BM25 与向量融合排序。

模型密钥仅保存在本机 `.env` 与本机运行期加密配置中，不应提交或转发。

## 停止与排查

- 停止服务：在本目录命令行执行 `docker compose down`。
- 查看应用日志：`docker compose logs --tail=100 app`。
- 查看服务状态：`docker compose ps`。
- 首次构建和 Elasticsearch 初始化通常需要 1 至 3 分钟；健康检查返回 `status: ok` 后再使用。

## 局域网验收

同一局域网内，将 `127.0.0.1` 替换为运行机器的 IPv4 地址，例如 `http://192.168.x.x:8201/`。若无法访问，请在 Windows 防火墙中允许专用网络的 TCP `8201` 入站连接。
